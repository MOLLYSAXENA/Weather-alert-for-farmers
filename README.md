# Weather-alert-for-farmers
## Made-using-Django
Wheather Alert System for Farmers:
This project is web-based Wheather Alert System for Farmers built using Django.
It hepls farmers to get timely weather updates and alerts so they can take better decisions related to farming to improve their productivity and incease their profit.

### OBJECTIVE:-
To provide early weather alerts.
To reduce crop damage.
To earn more profit.
To improve decision making in agriculture

### FEATURES:-
- Display weather
- easy user interface
- simple and user friendly
- web-based access
- integrated with OpenWeather API
- can download PDF

### Technology used:
-python
-Django
-SQLite
-HTML, CSS, Javascript

### how to run the project:
1. Clone the repository:

git clone https://github.com/your-username/your-repo-name.git

2. Go to project folder:

cd Weather-alert-for-farmers

3. Install dependencies:

pip install -r requirements.txt

4. Apply migrations:

python manage.py migrate

5. Run the server:

python manage.py runserver

6. Open in browser:

http://127.0.0.1:8000/
